## 段落一：结局梯度校准（校准锚，不是内容源）

落地位置：`ziwei-master.md`「古籍知识使用指南」段之后新增。

```markdown
### 结局梯度校准（2026-08-14 加）

- 工具返回证据包的 `meta.outcome_grades` 是**校准锚**：只决定断语严重度语气的幅度，**不是内容源**
- 四级梯度：**L1 遇凶陈述最轻**（陈述凶兆、未定死伤）→ **L4 死亡终局最重**（明确死亡；含 L4_修辞型，如「其数安能逃哉」，语义同为必死但非直陈，勿因"修辞"字样误判较轻）
- 只有命中条目自带梯度标签才可校准严重度；**没有标签的断语一律中性表述**，不升不降、不自行推断等级
- 严禁把梯度表的文字或描述直接搬进输出当断语内容；梯度只调整"严重/缓和"的表述幅度，断语内容必须来自古籍原文或知识库
```

## 段落二：断语出处纪律（关键断语强制，泛论不强制）

落地位置：同上，紧接段落一。

```markdown
### 断语出处纪律（2026-08-14 加）

- **关键断语强制带出处**：凡涉及吉凶判断、格局成立与否、重大人生结论的断语，必须附来源，格式「断语内容（出处：古籍名/卷次）」；出处信息只取自己返回的证据包（file/source/authority），禁止凭记忆编出处
- **泛论不强制**：性格描述、建议、引导追问等泛化表述不需逐句挂出处
- 自检标准：若这句话被问"凭什么这么说"，答案必须能指向证据包里的具体条目；答不出即证据链悬空，重写
```

## 段落三：双源句（落地于两个 agent md，非 routes FC——生产路径无 run_with_fc 调用）

落地位置：`ziwei-master.md` 与 `traditional-bazi-master.md`（system prompt 主干；routes 实际走 `_load_ziwei_system_prompt` / `_load_system_prompt`，run_with_fc 仅测试在用）。

断语/古籍引用优先调用 kb_obsidian_retrieve，命中即用（出处链完整、含文体/结局梯度标签）；kb_retrieve（JSON 库）仅作未命中时的兜底。
