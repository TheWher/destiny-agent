# 紫微 · 格局 · 破格

破格列标注的证据页。引擎 detect_patterns 44 格仅 3 格带 breaking（2026-08-14 底单 [[geju_breaking_inventory_20260814]]），破格列为欠账；本文为 2026-08-14 爬取的教材原文核验记录，机器消费走 [[geju_breaking_annotations_v1]]，本文供人读与 LLM 检索，两个源同进同出。

## 传承链钉子（2026-08-14 核）

- **陆斌兆《紫微斗数讲义》**：五十年代油印本，开班教材，从未公开发行。原文部分（如"遇火星铃星为火贪格……辰宫戌宫为上格，丑宫未宫为次格"、"贪狼在命宫有空曜天刑者反主清白端正"）出自此
- **王亭之补注《紫微斗数讲义评注》**：王亭之 1986 年（前言落款"八六年夏于濠江客次"）补注出版，见 kancloud 电子版前言。**评注（一）~（六）等"笔者"段是王亭之补注文字，不是陆斌兆原文**
- 纸本：博客来《陸斌兆紫微斗數講義評註》ISBN 9789573511236（台湾紫微系列，平装 512 页初版），与电子版比对待办
- **关系修正**：王亭之师从刘惠苍（非直系陆斌兆），刘师之学与陆斌兆同源；王亭之是**补注**陆斌兆讲义。韩湘生 2026-08-14 所说"王亭之师从中州派陆斌兆"不精确，以本文为准

## 火贪/铃贪 破格条目（结论 + 出处链整包）

### 1. 三方四正见擎羊/陀罗/化忌 → 横发横破，先得后失
- **出处**：王亭之补注《紫微斗数讲义评注》贪狼篇评注（三）："火贪格和铃贪格，如在三方四正更有擎羊、陀罗、化忌等，则需防横发横破，先得后失，一切仅是纸上富贵，尤其不利投机"
- **日期/方法**：2026-08-14 国学典籍网电子版核读
- **判定**：breaking（downgrade），ht-brk-004
- 附："贪狼最喜得火星、铃星，最畏则是擎羊、陀罗"（同段，王亭之补注）——羊陀为贪狼第一忌曜

### 2. 贪狼化忌再见昌曲 → 暴发转暴败
- **出处**：神机阁·贪狼化忌篇（shenjige.cn）："贪狼化忌与火铃同度，亦主突发……若凶，则为暴起暴跌"；"贪狼化为忌星，又见桃花昌曲诸曜，则常常主爱情上的争夺"
- **日期/方法**：2026-08-14 网页核读
- **判定**：breaking（downgrade），ht-brk-002

### 3. 贪狼与火星（铃星）同宫且同宫见擎羊/陀罗 → 不符此格（硬性排除）
- **出处**：通行教材（易水盟系，韩湘生 2026-08-14 核验）；王亭之补注同段佐证（贪狼最畏羊陀）
- **判定**：breaking（reject），ht-brk-001 / lt-brk-001
- **v1.3 限定**：reject 需「贪狼与火/铃同宫」前提（2026-08-14 构造盘清单暴露：会照盘上火星与贪狼不同宫，原条件文本会误触发）

### 4. 空劫：语境拆分结论（分歧样板）
- **王亭之**："火贪铃贪见空劫刑忌，主暴发暴败"（韩湘生转述核验，一手出处未直接抓到，待补）——**空劫+刑忌复合并见**
- **陆斌兆讲义原文**："贪狼在命宫，有空曜天刑者，反主清白端正"——但这是**贪狼坐命清白格语境**，非火贪格语境，不构成火贪格破格的直接冲突
- **知乎系**："不怕空劫，空劫会贪狼，反能习正；只怕羊陀"（贪狼一般语境）
- **拆分结论**：复合条件（空劫+刑忌）→ breaking（ht-brk-003）；单见空劫 → weakener（ht-wkn-001），disputed=true，schools 列三家
- **仲裁落点**：单空劫若需取判定依据，火贪格语境的直接陈述仅王亭之（rank2）与知乎系（rank4），取王亭之减分说，异说脚注带出，解读注明"另有 X 派持 Y 说"

### 5. 弱化项（weakener，减分不破格）
- 紫贪同宫成火贪：受帝曜制约，暴发性质减弱（王亭之补注评注（三）："紫微贪狼同度，因贪狼受紫微帝曜控制，故暴发的性质受到约制"）——ht-wkn-002
- 廉贪同宫成火贪：性质浮荡，发而不能耐久（王亭之补注评注（三）："廉贞贪狼同度，则性质过于浮荡，发而不能耐久"）——ht-wkn-003

## 成格分档（grade_tiers，归骨架表，不参与破格判定）

- **辰戌上格**、**丑未次格**、**他宫更次**（陆斌兆讲义原文："以辰宫戌宫为上格，丑宫未宫为次格，其他宫位更次之"）
- **异说**：章真言（8698.tw 紫微学堂）主张仅戌宫火铃庙旺才算真正成格（辰宫火铃落陷），与陆斌兆辰戌上格分歧；按 authority_rank 取陆斌兆（rank2），章真言（rank4）作脚注
- 附：火贪大旺于铃贪，铃贪持久于火贪（章真言）
- **三方口径的教材依据（2026-08-14 定）**：易水盟教材原文有放宽版「贪狼守命宫、财帛宫、官禄宫、迁移宫、田宅宫或身宫之一」。故引擎「贪狼坐命三方」成格条件有直接教材支撑，不是无意识收紧。8.3%（旧引擎任何宫位同宫）非教材口径，教材严格口径（贪狼守命）实测仅 ~1.5%，三方口径 ~5.5% 比它宽。庙旺只影响 level 不影响检出

## 负结果档（查过，没有就是没有）

- **「煞重≥3」古籍无量化表述**：底单 3 格（君臣庆会/杀破狼/机月同梁）的 breaking 全为通行归纳，无古籍原文直接支撑；「三方硬煞≥3」是引擎自定阈值，已归通行归纳档，不得当铁律
- **古籍对破格条件普遍少写**：《全书》《骨髓赋》等原文对"不成格"基本不设条文，破格规则多为后世归纳（mose 2026-08-14 定，底单数据佐证：44 格仅 3 格有 breaking 且全为归纳）
- **26 格完全无出处**：底单 source 现状，10 格裸标「《紫微斗数全书》」无篇目，格式统一进行中
- **王亭之"见空劫刑忌"一手出处未抓到**：只核到韩湘生转述 + 补注版前言底本，原文具体卷次/页码待补
- **杀破狼格「坐空劫」口径已定（2026-08-14）**：对齐底单/旧引擎原义 = 三方四正会空劫（sf_set & SHA_KONG）。v3 对照表逮到消费口窄化为命宫坐空劫，韩湘生已修代码+JSON 条件。依据：底单就是引擎 breaking 的权威锚，消费口不得悄悄窄化
- **评注段归属**：国学典籍网《陆斌兆紫微斗数评注》的评注段（"笔者"口吻）判定为王亭之补注文字，纸本 ISBN 9789573511236 待比对确认
