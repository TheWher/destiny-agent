# 逐星双口径总表

横切样板：十四主星每行一星，飞星要点 / 古籍要点 / 主要冲突。每格一两句，长则 wikilink 素材。骨架 2026-08-11 立，前三星为样板，余星待续填。**2026-08-11 十四星全填完成**（飞星列取自 14 篇素材核心段，古籍列取自《全书》各星条）。

| 星 | 飞星要点（ziweicn 炎一） | 古籍要点（《全书》） | 主要冲突 |
|----|------------------------|---------------------|---------|
| 紫微 | 帝星，己土埋土，认领护卫（天机/太阳/武曲各就其位），入父母照疾厄 | 帝座官禄主，"不入庙无左右为孤君" | 飞星不论紫微亮度；古籍有紫微庙旺概念（孤君=结构非亮度） |
| 天机 | 师爷智多星，乙木，善机变；**"我派不看除日月以外主星亮度"** | 南斗化善星兄弟主，"入庙身长肥胖"、"乙丙丁生人遇之入庙化吉" | **最大张力**：飞星不看天机亮度 vs 古籍"入庙"记载 |
| 太阳 | **"先看亮不亮"**：落宫/日夜/冬至夏至三因素；失辉=不能公开之事、夫星不明 | "夜生陷日生庙旺"、"庙旺终身富贵，陷地虽化权禄也凶" | 两派都重亮度但口径不同：飞星三因素 vs 古籍日夜+宫位；"庙旺"档位数不一 |
| 武曲 | 先天修道星、后天财帛星，辛金，财帛主正财星兼寡宿，“过刚则折”气质（[[2026-08-11-ziweicn-wuqu-xing]]） | 北斗财星，“武曲化忌往往为败局”、“过刚则折” | 寡宿/财星两派共识；亮度上飞星不看、古籍有武曲庙旺记载 |
| 天同 | 福星，各地支宫位论述（水澄桂萼、明珠出海等格局取象）（[[2026-08-11-ziweicn-tiantong-xing]]） | 南斗福星喜化禄，“天同如陀忌肥满而目眇” | 小；两派同视为福星 |
| 廉贞 | 化囚、次桃花、静态官禄主、五鬼星（[[2026-08-11-ziweicn-lianzhen-xing]]） | 化气为囚次桃花，“主感情与理智”、“遇善则善遇恶则恶” | 小；囚性两派共识 |
| 天府 | 戊土阳土，田宅主兼财帛主一星两用，南斗第一星（[[2026-08-11-ziweicn-tianfu-xing]]） | 南斗星主财库，“喜群臣同会” | 飞星不论天府亮度 vs 古籍有天府庙旺记载 |
| 太阴 | 月相论强弱（月中生人圆满/上弦渐强/下弦渐弱），化忌反能刚柔并济（[[2026-08-11-ziweicn-taiyin-xing]]） | “酉戌亥垣为得地”、“太阴入庙化权星清秀聪明” | 飞星只看日月 vs 古籍记太阴得地宫位（见 [[笔记/亮度口径对照]]） |
| 贪狼 | 甲木癸水，欲望之神桃花星，神仙之宿，“本贪”（[[2026-08-11-ziweicn-tanlang-xing]]） | 化气桃花，“须得制化始有作为” | 小；桃花/欲望两派共识 |
| 巨门 | 以贪狼为交际方式、太阴为夫官等取象，暗曜性质（[[2026-08-11-ziweicn-jumen-xing]]） | 暗曜，“得庙旺太阳会照或禄权始可解其暗” | 亮度：古籍记巨门庙旺（靠太阳解暗） vs 飞星不看巨门亮度 |
| 天相 | 壬水，与破军互为表里，衣禄之神（[[2026-08-11-ziweicn-tianxiang-xing]]） | 化气为印，衣禄之神，“天府天相乃为衣禄之神” | 小 |
| 天梁 | 戊土，父母主，荫星，天储为体（[[2026-08-11-ziweicn-tianliang-xing]]） | 司寿化荫父母主，“荫福聚不怕凶恶” | 小；荫星两派共识 |
| 七杀 | 丁阴火辛阴金，斗中上将肃杀之气，杀破狼变动格局（[[2026-08-11-ziweicn-qisha-xing]]） | 斗中上将，“肃杀”、“成败之孤辰” | 小；肃杀两派共识 |
| 破军 | 阴水阴金，化气为耗，夫子女仆主，“破坏后的建设”（[[2026-08-11-ziweicn-pojun-xing]]） | 化气为耗，“破军恐临水以生灾” | 小；耗星两派共识 |
