# 识典古籍书影抓取方法

> 2026-08-14 在 SDZJ0170 项目实测打通，可复用于识典其他古籍。

## 核心结论

识典书影图可通过章节页 SSR 数据的 `previewPages[].picUrl` 字段直接获取（签名 CDN），无需登录、无需浏览器渲染。

## 链路

1. 章节页 URL：`https://www.shidianguji.com/book/{bookId}/chapter/{chapterId}`，公开可访问
2. SSR HTML（约 300-500KB）内嵌完整数据：`paragraphList`（行级文本）、`translateContent`（白话翻译）、`previewPages`（书影图）、`catalog`（目录含 subChapters）
3. 书影图 URL 模式：
   `https://{p3|p6|p9}-ancientlib-sign.byteimg.com/tos-cn-i-ceu0di7tn2/read/{bookId}/{vol}/page/{hashA}/{hashB}-{bookId}_{vol}_{page}.webp~tplv-ceu0di7tn2-png.png?lk3s=e5c95217&x-expires={ts}&x-signature={sig}`
   - 签名过期：x-expires≈3 周有效，过期后重新抓 SSR 换新签名
   - 原始 webp 路径（无签名）在 `uri` 字段，需拼 CDN 域名
4. 图片质量：实测高清 PNG（约 3.6MB/张），AI 读图可识别竖排古籍文字

## 解析要点

- SSR 内 URL 双重转义：`\\u002F` → `/`，Python 用 `html.replace('\\u002F','/')`
- 段落对象用 `json.JSONDecoder().raw_decode()` 从任意位置解析，绕开转义坑
- 目录必须展开 `subChapters`：卷目录下藏着子章节（命例/註觧/宫位断法等），只抓 L1 会漏大量内容
- 目录 chapterId↔名称映射有错位风险（实测吕太后命 ID 指向小児夭命），多章节抓取前先抽查

## 风控教训

- 连续高频抓取（8 并发 142 章）触发风控，返回 2.5KB 验证壳（含 captcha 脚本）
- 触发后所有章节均不可抓（包括之前正常的），冷却约 15-30 分钟
- 对策：单线程 + 间隔 3-5 秒 + 低并发；大批量分批跑

## 行级数据字段

- `lineType`：1=正文、2=注文（小字夹注）、3=页界（content 空、带 pagePass.PageId）、10=标题
- 注文无白话翻译（识典结构性不翻）
- 行级 PageId（19 位数字）是内部序数，与原书页标（catalog.startPageNum）是两个坐标系，注意换算
