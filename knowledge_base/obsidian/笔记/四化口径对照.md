# 四化口径对照

同一概念"四化"在两套话语里框架不同、处置不同。跨体系引用先过 [[四化]] 消歧页分流，本笔记并置口径差异，套跨体系对照模板。

## 三合口径（古籍传统）

- **四化 = 星曜静态属性**：生年四化按年干排布（古籍歌诀），非动态飞化
- **化忌 = 凶星，断语式定性**：
  - "陷地虽化权禄也凶"（《全书》太阳条，[[2026-08-11-ziwei-quanshu-quanlan]]）
  - "禄逢冲破，吉处藏凶"（太微赋：化禄最忌冲破，[[笔记/古籍断语标注]]）
  - "武曲化忌往往为败局"（逐星总表古籍列，[[笔记/逐星双口径总表]]）
- **处置**：化忌当凶，需化解/避让（吉星化忌减吉、凶星化忌加凶）
- **语体**：断语式（吉/凶/忌定性，一句话判完）

## 飞星口径（梁若瑜系 / 刘韫龄取象派）

- **四化 = 动态框架**：生年四化只是起点，宫干飞化、自化（向心/离心）、来因宫才是重头（[[紫微-四化-飞星]] MOC）
- **化忌 = 应事之钥，取象式解读**：根系深扎（树喻：忌是根、科是叶、禄是果），"没有经历过化忌的作品和人生是不值得品味的"，深度专研必过化忌（[[笔记/化忌取象（飞星）]]）
- **化忌导致原路不通 → 换方式前行**：不同星曜化忌含义不同但取象相通（文昌/贪狼/武曲化忌）
- **语体**：取象/比喻式（树、根、低谷）

## 差异收敛结论（2026-08-11）

> **主分水岭：化忌的处置**——三合把化忌当凶星（断语式：吉凶定性、化解避让），飞星把化忌当应事之钥（取象式：低谷即养分、深度专研的必经）。差异在"处置与权重"，不在"化忌有无"：两系都认化忌是四化的重头，三合停在吉凶判断，飞星继续往下取象应事。

观察位应验（2026-08-11 mose 定）：与 [[笔记/亮度口径对照]] 同构——**三合静态定性 vs 飞星动态应事**，两站收敛到同一形态。

## 局限（如实标）
