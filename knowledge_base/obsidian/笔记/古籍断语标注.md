# 古籍断语标注（赋文分篇）

古籍赋文断语速查，每条标**星曜归属**与**性质（吉/凶/忌）**，填总表古籍列直接引用，不用回原文翻。来源为赋文注解分篇，双口径并收：三合侧王亭之《太微赋》精解，飞星侧刘韫龄《全书》分篇注解。

## 亮度相关表述汇总（单独留意）

> 与 [[笔记/亮度口径对照]] 互相印证："亮度是唯一大分水岭"的又一实证层。

| 出处 | 亮度表述 | 口径 |
|------|---------|------|
| 王亭之《太微赋》精解 | 入庙为奇，失数为虚；星系入十二垣各有庙旺陷为三十六位 | 中州派：庙旺利陷四等，"利"=平和 |
| 王亭之《太微赋》精解 | 星临庙旺，再观生克之机（宫星生克+星星生克） | 亮度非唯一判据 |
| 王亭之《太微赋》精解 | 廉贞贪狼只能在巳亥二宫，同时一定落陷 | 星系固定亮度 |
| 王亭之《太微赋》精解 | 日月最嫌反背（日月居陷宫） | 日月亮度 |
| 刘韫龄撮要六问断 | 太阴文昌受制反不为福，若居庙旺则富贵 | 飞星侧也认庙旺富贵 |
| 刘韫龄起例歌诀 | 十二宫分详庙陷，流年祸福此中分 | 庙陷分祸福 |
| 刘韫龄看命总论 | 阴星主武，在庙旺又在阴宫则为武勇刚猛 | 庙旺加强星性 |
| 刘韫龄骨髓赋注 | 或在恶限积百万之金银，或在旺乡遭连年之困苦 | 旺乡不等于福（辩证） |

**要点**：三合侧（王亭之）承认亮度但强调六十星系已融会庙旺利陷；飞星侧（刘韫龄）在古籍注解中保留"庙旺"表述，但其现代取象体系只看日月（对照 [[笔记/亮度口径对照]]）。两篇注解都给了"亮度是两系大分水岭"的实证：同一句"庙旺"断语，三合直接引用，飞星保留原文但归入取象综合判断。
