# <table>：表格元素
基线 * 
自 2015年7月 起，此特性已在主流浏览器中得到支持，可在大多数设备和浏览器版本中正常使用。
* 此特性的某些部分的支持程度可能有所不同。


[HTML](https://developer.mozilla.org/zh-CN/docs/Web/HTML) **`<table>`**元素表示表格数据——即在一个由包含数据的行和列组成的二维表格中呈现的信息。  
 |  
|  |  
| 允许的内容  |  按照这个顺序： 
  1. 一个可选的 [`<caption>`](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Elements/caption) 元素
  2. 零个或多个的 [`<colgroup>`](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Elements/colgroup) 元素
  3. 一个可选的 [`<thead>`](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Elements/thead) 元素
  4. 下列任意一个： 
     * 零个或多个 [`<tbody>`](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Elements/tbody)
     * 零个或多个 [`<tr>`](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Elements/tr)
  5. 一个可选的 [`<tfoot>`](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Elements/tfoot) 元素

 |  
| 标签省略  | 不允许，开始标签和结束标签都不能省略。  |  
| 允许的父元素  |  任何支持流式内容的元素   |  
| 隐含的 ARIA 角色  |   |  
| 允许的 ARIA 角色  | 任意  |  
| DOM 接口  |  
此元素包含所有的[全局属性](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Global_attributes)。 

[`align` ](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Elements/table#align)
    
这个[枚举](https://developer.mozilla.org/zh-CN/docs/Glossary/Enumerated)属性指定了包含在文档中的表格必须如何对齐。可能含有如下值：
  * `left`：表格将在文档左侧显示；
  * `center`：表格将在文档中央显示；
  * `right`：表格将在文档右侧显示；


设置 [`margin-left`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/Properties/margin-left)、[`margin-right`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/Properties/margin-right) 为 `auto`，或者将 [`margin`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/Properties/margin) 设置为 `0 auto` 来实现类似于 align 属性的效果。 

[`bgcolor` ](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Elements/table#bgcolor)
    
表格的背景颜色。它是一个 [6 位的十六进制 RGB 编码](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/Values/hex-color)，以 `'#'` 作为前缀。当然也可以使用下面已经被预先定义的[颜色关键字](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/Values/named-color)。
为了实现相似的效果，可以使用 CSS 属性 [`background-color`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/Properties/background-color)。 

[`border` ](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Elements/table#border)
    
这个整型属性定义了环绕表格外部的框的大小。如果设置为 0，这意味着 [`frame`](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Elements/table#frame) 属性被设置为空。
为了实现相似的效果，可以使用 CSS 简写属性 [`border`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/Properties/border)。 

[`cellpadding` ](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Elements/table#cellpadding)
    
这个属性定义了一个单元格的内容和它的边框之间的空间，无论显示与否。如果 cellpadding 的长度是用像素定义的，这个像素大小的空间将被应用到单元格内容的所有四边。如果长度是用百分比值定义的，内容将被居中，总的垂直空间（顶部和底部）将代表这个值。对于总的水平空间（左边和右边）也是如此。
为了实现相似的效果，可以在 `<table>` 元素上使用属性值为 collapse 的 [`border-collapse`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/Properties/border-collapse) 属性，在 [`<td>`](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Elements/td) 元素上使用属性 [`padding`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/Properties/padding)。 

[`cellspacing` ](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Elements/table#cellspacing)
    
这个属性定义了水平和垂直方向上两个单元格之间空间的大小，使用百分比或像素，包括了表格的顶部与第一行的单元格、表的左边与第一列单元格、表的右边与最后一列的单元格、表的底部与最后一行单元格之间的空间。
为了实现相似的效果，可以在 `<table>` 元素上使用 CSS 属性 [`border-spacing`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/Properties/border-spacing)。`border-spacing` 在 [`border-collapse`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/Properties/border-collapse) 设置为 collapse 时将无效。 

[`frame` ](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Elements/table#frame)
    
这个枚举属性定义了包围在表格周围的框架的哪个边必须显示。
为了实现相似的效果，可以使用 CSS 属性 [`border-style`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/Properties/border-style) 和 [`border-width`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/Properties/border-width)。 

[`rules` ](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Elements/table#rules)
    
这个枚举属性定义了在一个表格中分隔线的显示位置。它可以有以下值：
  * `none`，这表明没有分隔线将被显示；这是默认的值；
  * `groups`，这将使得分隔线只显示在行组（row group，通过 [`<thead>`](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Elements/thead)、[`<tbody>`](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Elements/tbody) 和 [`<tfoot>`](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Elements/tfoot) 元素定义）和列组（column group，通过 [`<col>`](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Elements/col) 和 [`<colgroup>`](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Elements/colgroup) 元素定义）之间
  * `rows`，这将使得分隔线在行之间显示；
  * `cols`，这将使得分隔线在列之间显示；
  * `all`，这将使得分隔线在列和行之间显示；


为了实现相似的效果，可以在适当的 [`<thead>`](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Elements/thead)、[`<tbody>`](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Elements/tbody)、[`<tfoot>`](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Elements/tfoot)、[`<col>`](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Elements/col) 或 [`<colgroup>`](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Elements/colgroup) 元素上使用 [`border`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/Properties/border) 属性。 

[`summary` ](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Elements/table#summary)
    
该属性定义了概括表格内容的替代文本。请使用 [`<caption>`](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Elements/caption) 元素代替。 

[`width` ](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Elements/table#width)
    
该属性定义了表格的宽度。请使用 CSS [`width`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/Properties/width) 属性代替。
#### 对表格的行进行排序
没有原生的方法对 HTML 表格的行（[`<tr>`](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Elements/tr)元素）进行排序。但是通过使用 [`Array.prototype.slice()`](https://developer.mozilla.org/zh-CN/docs/Web/JavaScript/Reference/Global_Objects/Array/slice)、[`Array.prototype.sort()`](https://developer.mozilla.org/zh-CN/docs/Web/JavaScript/Reference/Global_Objects/Array/sort)、[`Node. removeChild()`](https://developer.mozilla.org/zh-CN/docs/Web/API/Node/removeChild) 和 [`Node.appendChild()`](https://developer.mozilla.org/zh-CN/docs/Web/API/Node/appendChild)，你可以实现你自己的 `sort()` 函数来对 `<tr>` 元素的[`HTMLCollection`](https://developer.mozilla.org/zh-CN/docs/Web/API/HTMLCollection) 进行排序。

网络上表格的一个普遍问题是，当内容量很大时，它们在小屏幕上的原生效果并不好，而且使它们可滚动的方法并不明显，特别是当标记可能来自 CMS，无法添加一个包装器时。
这个例子提供了一种在小空间中显示表格的方法。我们隐藏了 HTML 内容，因为它非常大，而且没有什么特别之处。在这个例子中，研究其 CSS 代码更有用。
当查看这些样式时，你会注意到表格的 [`display`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/Properties/display) 属性已被设置为 `block`。虽然允许滚动，但表格失去了一些完整性，而且表格单元格会尽量变小。为了缓解这个问题，我们在 `<tbody>` 上将 [`white-space`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/Properties/white-space) 设置为 `nowrap`。然而，我们没有对 `<thead>` 进行设置，以避免长标题迫使列的宽度超过显示数据所需的宽度。
为了在向下滚动时保持表头在页面上，我们在 `<th>` 元素上将 [`position`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/Properties/position) 设置为 sticky。注意，我们**没有** 将 [`border-collapse`](https://developer.mozilla.org/zh-CN/docs/Web/CSS/Reference/Properties/border-collapse) 设置为 `collapse`，因为如果我们这样做，表头就不能与表格的其他部分正确分开。
#### 结果
提供一个清晰简洁地描述了表格的目的 [`<caption>`](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Elements/caption) 元素，有助于人们决定是否需要阅读表格的其他内容或跳过它。
这有助于借助辅助技术（如屏幕阅读器）进行导航的人、经历低视力状况的人和有认知问题的人。

头部元素的 [`scope`](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Elements/th#scope) 属性在简单情况下是多余的，因为范围是推断出来的。然而，一些辅助技术可能无法做出正确的推断，所以指定头的范围可能会改善用户体验。在复杂的表格中，可以指定范围以提供与标题相关的单元格的必要信息。
#### 示例
在 [`<th>`](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Elements/th) 元素上提供声明 `scope="col"`，将有助于描述该单元格处于一列的顶部。在 [`<th>`](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Elements/th) 元素上提供声明 `scope="row"`，将有助于描述该单元格是某一行的第一个。

诸如屏幕阅读器等辅助技术可能难以解析那些复杂到标题单元不能以严格的水平或垂直方式关联的表格。这通常由 [`colspan`](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Elements/td#colspan) 和 [`rowspan`](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Elements/td#rowspan) 属性的存在表示。
理想情况下，考虑用其他方式来展示表格的内容，包括将其分解成一系列较小的、相关的表格，而不必依赖 `colspan` 和 `rowspan` 属性。除了帮助使用辅助技术的人理解表的内容外，这也可能有利于有认知障碍的人，这些人可能难以理解表的布局所描述的关联。
如果表格不能被拆开，使用 和 [`headers`](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Elements/td#headers) 属性的组合，以编程方式将每个表格单元与该单元所关联的标题相关联。
